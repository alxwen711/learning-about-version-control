# learning-about-version-control
Learning About Version Control


Solving merge conflicts takes conscious effort, but I can do it!


What I like most about version control is being able to access past versions of my work very easily and being able to view differences between each version, at least compared to the alternative of creating new versions of each project locally for minute changes being much more tedious.

One of the current challenges with version control I find most significant is resolution of merge conflicts purely within Git; I have done this to some extent before but this is with several useful external tools aiding me (Sourcetree, BitBucket).
